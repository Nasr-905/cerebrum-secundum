Transfer learning involves taking a model pre-trained on a large, general dataset (e.g., ImageNet) and adapting it to a new, specific task or domain (e.g., gel formation analysis). This is done by:

1. **Fine-Tuning**: Updating the weights of the pre-trained model using a smaller, task-specific dataset.
    
2. **Feature Extraction**: Using the pre-trained model as a fixed feature extractor and training a new classifier on top of it.
